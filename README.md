# ☕ Brew & Bean Coffee Shop — Sales Analysis

## Project Overview
This project analyzes 550 simulated coffee shop transactions to understand sales performance, product popularity, customer payment preferences, and peak operating hours.

The objective is to transform raw transactional data into meaningful business insights that can support decision-making.

## Tools Used
- **Microsoft Excel:** Data cleaning, preprocessing, and PivotTables
- **MySQL Workbench:** SQL queries and business analysis
- **Canva:** Dashboard design and data visualization

## Project Workflow

### 1. Data Cleaning — Excel
- Identified and handled missing values
- Standardized product names and payment methods
- Corrected inconsistent currency formats
- Validated transaction amounts
- Prepared the dataset for SQL analysis

### 2. Data Analysis — MySQL
Used SQL queries to investigate:
- Overall sales performance
- Best-selling products by revenue
- Busiest operating hours
- Revenue by weekday
- Preferred payment methods
- Revenue contribution by product category
- Dine-in versus takeaway performance

### 3. Data Visualization — Canva
Designed a static sales dashboard presenting KPIs, product performance, revenue distribution, and customer purchasing patterns.

## Key Learnings
This project strengthened my skills in Excel data cleaning, SQL aggregation, data validation, analytical thinking, and communicating business insights.

## Dataset
This project uses synthetic transaction data created for educational and portfolio purposes. It does not represent actual coffee shop sales.
